# V-AID Vision Board

Interactive vision board for V-AID, a legged robot dog with an arm and a memory (capstone concept, V1.1).

Live site: https://parthaped.github.io/V-AID/

The page is a single self-contained HTML file (`index.html`) with embedded three.js digital-twin animations. Open it locally or use the "Present full screen" button for slideshow mode (arrow keys to move, Esc to exit).
